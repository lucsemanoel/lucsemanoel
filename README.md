# Lucas Emanoel

**Full Stack Developer** · Python · Django · Django REST Framework · PostgreSQL · React Native

Full stack developer from Canguaretama, RN, Brazil. I work from data modeling and REST APIs to the interface, including authentication, role-based access control and production deployment. Technology Degree in Internet Systems from **IFRN** (2026).

Currently a freelance full stack developer at **Mac Madeiras**, where I built and maintain **MacNF**, an invoice management system running in production in 3 stores, with 11+ users and 250+ invoices per month.

## Highlights

- **MacNF** (Mac Madeiras): replaced invoice tracking over WhatsApp with a single platform. REST API built from scratch with Django REST Framework and JWT, 3 access roles, audit history, automatic CNPJ and NF-e access key validation, and signed-URL PDF storage on Cloudflare R2. Deployed on Railway with PostgreSQL.
- **Portfolio and Web Bulletin Board** (IFRN): backend in Django, in production, with institutional SSO login through SUAP and role-based permissions.
- **Smart Reservoir** (capstone project, grade 100): React Native app for water monitoring via IoT, validated with 61 test cases in 14 suites (unit, integration and system), all passing.
